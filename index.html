常见问题

支持哪些格式？
输入：JPG、PNG、HEIC、WebP 等系统可解码的格式；输出：JPEG、PNG、HEIC。“按大小”和“尺寸+大小”模式下不提供 PNG（无损格式无法控制文件大小）。

保存失败 / 提示没有照片权限？
请前往“设置 › 隐私与安全性 › 照片 › 随心缩”，选择“仅添加照片”或“完全访问”。

为什么达不到目标大小？
目标过小时，应用会在降低画质的同时自动缩小尺寸；若仍无法达到，会给出最接近的结果并提示。

图片会上传吗？
不会。所有处理都在你的设备上完成，详见 隐私政策。

字太小？
在应用“设置”中打开“长辈模式”，可获得更大的字体和按钮。

FAQ

Which formats are supported?
Input: JPG, PNG, HEIC, WebP and other formats iOS can decode. Output: JPEG, PNG, HEIC. PNG is not offered in File size / Both modes (lossless, so the file size can’t be targeted).

Saving fails / “Photos access is turned off”?
Go to Settings › Privacy & Security › Photos › EasyResize and choose “Add Photos Only” or “Full Access”.

Why wasn’t the target size reached?
For very small targets the app lowers quality and then automatically reduces dimensions; if the target still can’t be met, it shows the closest result with a note.

Are my images uploaded?
No. Everything is processed on your device. See the Privacy Policy.

Text too small?
Turn on Elder mode in the app’s Settings for larger text and buttons.
